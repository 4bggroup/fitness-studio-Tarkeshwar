# Motion House — Mock-Matched One-Page Website

## What this build matches

This edition is designed to follow the **black / champagne-gold reference mockup** shown in the conversation, not the unrelated V13 layout.

The layout recreates its four signature rows:
1. Large photo hero (left) paired with a studio image and five zone thumbnails (right).
2. Cream goal-selector panel opposite the dark four-image programmes panel.
3. Large coaching photograph opposite a dark progress/story panel.
4. Cream four-step first-visit flow opposite a photographic booking call-to-action.

The one-page site continues with extended studio editorial, training programme details, image gallery, FAQs, enquiry preparation and the footer credit **Created by Sourav Show**.

## Run

Extract the full ZIP and open `index.html`, or upload the folder contents to a standard static web host. Keep the `assets/` directory alongside `index.html`, `styles.css`, and `script.js`.

## Before publishing

- **Motion House** is a placeholder brand.
- Images are concept/generated photos. They are not photographs of a verified studio in Tarakeswar.
- Replace images with actual studio images if authenticity to a physical location is needed.
- Verify services, trainer qualifications, prices, address and contact methods before adding claims.
- The enquiry form validates inputs and generates a copyable message. It **does not send the message**, as no verified business inbox or WhatsApp number was supplied.
- Google Fonts are loaded online where available; fallback fonts are provided.

The reference mockup included invented review identities, membership totals and phone numbers. They have deliberately **not** been repeated in this implementation.
